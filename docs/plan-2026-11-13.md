## What the user must create on the Roblox website
Robux items and badges can't be created from code. Steps 14, 16 and 17 explain how to create them and
where to paste their IDs (`src/shared/Config.luau`). Until an ID is filled in, that feature is
switched off and the rest of the game still works.
