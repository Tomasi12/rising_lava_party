# Rising Lava Party

A round-based Roblox obby: the lava rises, the map changes every round, and the last players standing win coins.

## Tools
- [Roblox Studio](https://create.roblox.com/)
- [Rokit](https://github.com/rojo-rbx/rokit) to manage tools, which are listed in [`rokit.toml`](rokit.toml)
- [Rojo](https://github.com/rojo-rbx/rojo) to sync the code in this repo into Studio
